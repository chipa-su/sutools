# Language Flashcard Builder

Create themed, standalone single-file HTML language practice webpages tailored to a user's scenario and proficiency level. Always present the curated categories, vocabulary, and phrases for user confirmation before generating the final interactive webpage.

<!-- 【觸發時機】說明在什麼情境下（例如規劃特定旅遊、咖啡廳點餐、建築參訪等主題單字頁）應自動啟用這套流程。 -->
## When to Use

- The user wants a new language practice webpage or flashcard handbook for a specific goal (such as a trip, cafe ordering, architecture visits, shopping, or workplace scenarios).
- The user asks to reuse their established flashcard layout, audio playback, masking quiz mode, and progress sync format for a new topic.
- The user wants to review and adjust selected words, categories, and sentence patterns before turning them into a deployable HTML file.

## Steps

<!-- 【階段一：確認需求與程度】若提問缺少目的地、場景或日文程度，先簡短確認 1～2 個問題再開始規劃。 -->
### Step 1: Clarify Scope and Level

Identify the target language (default to Japanese if unspecified), theme or scenario, and learner proficiency level. If the user's request is missing critical context (such as the destination, purpose, or rough level), ask 1 to 2 brief clarifying questions before drafting.

<!-- 【階段二：列出單字與句型草案並暫停等待確認】絕對不跳過確認直接寫程式；先依 4～6 個情境分類列出單字、句型、聽力防禦與文法補充，並自動把關自然度（如避免結帳時用有歧義的「大丈夫です」）。 -->
### Step 2: Propose Content and Pause for Review

Before writing any HTML, present a structured draft of the study content in the chat and ask the user to review, add, remove, or reprioritize items. Never skip straight to HTML generation unless the user explicitly asks to skip review.

Organize the draft into logical thematic categories (typically 4 to 6 categories) that cover:

- **Core Vocabulary**: Word in native script, reading/kana, romanization with consistent long-vowel markers (e.g., macrons for Japanese), Chinese meaning, concise usage note, and a priority flag for high-frequency must-know items.
- **Situational Phrases**: Practical sentences using the learned vocabulary, with native script, reading, romanization, Chinese meaning, and quick substitution tips.
- **Listening Defense Q&A** (when relevant to real-world interaction): Common questions staff or locals ask, paired with short, natural, unambiguous replies.
- **Grammar or Pattern Notes** (when helpful for the learner's level): Simple formula cards with side-by-side usage explanations.

Check content accuracy before presenting:

- Prefer natural, unambiguous spoken replies (for example, in Japanese, use `いりません` or `結構です` rather than ambiguous `大丈夫です` when declining bags or receipts, and use `～抜きでお願いします` when removing food items).
- Keep reading scripts accurate (hiragana/katakana for Japanese) and standardize romanization long-vowel notation.
- Distinguish context-specific verbs (such as `試着` for trying on clothes vs. `履く` for trying on shoes).

<!-- 【階段三：依回饋微調清單】整合你的增刪修改與必背優先級調整，確認最終總數與分類結構。 -->
### Step 3: Refine Based on Feedback

Incorporate all user edits, additions, removals, and priority adjustments. Confirm the final item count and category structure.

<!-- 【階段四：生成零外部相依的單一 HTML 網頁】可直接上傳 GitHub Pages 在電腦、iPad 與手機跨裝置使用。 -->
### Step 4: Generate the Standalone Interactive HTML

Build a single, zero-dependency HTML/CSS/JS file (using the web code canvas preview tool when available) suitable for direct deployment on GitHub Pages across desktop, iPad, and mobile browsers.

<!-- 【版面骨架規範】鎖定全視窗高度，固定頂部標題／控制列／雙進度條（控制項配合右側卡片區置中）與左側莫蘭迪色大分類側欄，僅右側單字區可捲動。 -->
#### Layout and Visual Design

- **Viewport Lock**: Use a fixed full-viewport shell (`height: 100vh; overflow: hidden`) so the top control bar and left category sidebar stay stationary while only the main card area scrolls vertically.
- **Top Fixed Header**: Reserve the left header block (`240px` wide, aligned with the sidebar) for an enlarged title (`~23px`) with no extra reminder badges in the top-right corner. Center the control toolbar and elongated stacked dual progress bars (Must-Know % and Total %) relative to the right-hand card area.
- **Left Fixed Sidebar**: Display category buttons as tall, clearly bordered cards (`min-height: 70px`, `2px` border) using a low-saturation Morandi palette. Show category name and item count clearly; highlight the active category with a thicker colored border and soft tinted background.
- **Section Header**: Render the active category title and brief description directly on a transparent background with only a subtle bottom divider (no filled banner box).
- **Color Palette**: Use a clean, low-saturation Japanese editorial style with a warm off-white page background (`#F7F8FA`), crisp white cards (`#FFFFFF`), and high-contrast dark text.

<!-- 【卡片密度與老花眼友善設計】桌機一列三張左右對分單字卡（左側嚴格三行：假名／漢字／拼音；右側中文與按鈕），全面放大字體；必背用粗紅框（不用星號），已熟記用柔綠底色。 -->
#### High-Density, Presbyopia-Friendly Cards

Maximize horizontal space to keep card height compact while enlarging font sizes for comfortable reading without eye strain
