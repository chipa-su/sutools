系統開發與演進日誌 (Changelog)

v2.2 - A4 分頁格線與精準所見即所得修正

2026-11-24
Print & Layout Precision
  • 即時 A4 分頁格線：內建隱藏式 100mm 校正尺換算螢幕 px/mm 比例，以 A4 每頁可印高度 257mm 自動繪製紅色虛線分頁線與左右 20mm 邊界參考線，並支援工具列一鍵開關。
  • 預估總頁數即時同步：左側新增「A4 列印預估卡」，列印按鈕亦即時顯示預估頁數；調整字級、行距、縮放圖片或增刪文字時，格線與頁數會自動重算。
  • 徹底解決列印跑版與縮放：列印模式解除外層 Flexbox 並嚴格鎖定 170mm 內容寬度，確保螢幕斷行與實體輸出 100% 一致；透過 CSS 變數同步字體大小與行距，並限制圖片放大上限與表格／程式碼自動折行，防止觸發瀏覽器整頁縮小。
  • 來源頁尾同步排版：將來源網址頁尾改為螢幕與列印同步顯示並納入高度計算，避免列印時意外多出空白尾頁。

v2.1 - 全純 Icon 工具列與開啟原始網址

2026-11-24
UI/UX Redesign
  • 新增開啟原始網址按鈕：網址列旁新增外開連結圖示，輸入有效網址後自動啟用，點擊可於新分頁檢視原始文章。
  • 純 Icon 化圓角設計：移除所有工具列按鈕與滑桿文字標籤，統一為 40×40px 圓角按鈕與適中圖示，滑鼠移過即刻浮現深色圓角 Tooltip 提示（調整字級／行距時即時更新數值）。
  • 視覺層級色彩區分：核心操作（擷取、列印）採實心醒目底色；常用特色功能（開啟原文、通道測試、雙色螢光筆、存檔）採柔色底配彩色圖示；一般編輯工具採俐落白底細框。

v2.0 - 五層多通道擷取引擎與圖片防破圖

2026-11-24
Major Upgrade
  • 五層自動降級擷取架構：移除已停用的 codetabs，改以 Jina Reader、Imread（支援 SPA 動態網頁並以 marked.js 轉譯）為優先，搭配 cors.lol、AllOrigins（Raw / JSON）+ Readability.js 備援。
  • 逾時中斷與防護頁偵測：加入 AbortController（10～14 秒逾時）與 Cloudflare／403 驗證頁過濾，不再卡死轉圈；內建「5 大網站通道測試」診斷工具，可直接實測成功率與耗時。
  • 圖片懶載入與防盜連補強：自動解析 data-original、data-lazy-src、srcset 並過濾 1×1 佔位圖；全面加上 referrerpolicy="no-referrer" 與 loading="eager" 降低破圖率。
  • 進階排版與細節修復：新增「隱藏所有圖片（省墨水列印）」開關、行距滑桿與「匯出獨立 HTML 存檔」；修正作者／發布時間樣式遭洗掉、螢光筆外框 CSS 無效，並將網址列改為聚焦自動全選＋獨立清除鈕與 Enter 快捷擷取。

v1.8 - 終極重構與效能優化版

2026-04-23 20:35
Refactoring
  • HTML 模板化：將冗長的錯誤提示畫面字串，移至原生的 <template> 標籤中，大幅提升代碼可讀性與後續維護性。
  • 邏輯抽象化：將圖片刪除、工具列定位等重複邏輯獨立封裝為共用函數（如 deleteSelectedImage），減少代碼冗餘。
  • DOM 操作精簡：優化了空白行清理與樣式過濾的迴圈寫法，提升執行效率，整體程式碼結構更加現代化與緊湊。

v1.7 - A4 所見即所得列印修正

2026-04-23 20:10
Print Optimization
  • 精準多頁留白：捨棄容器 padding，改用 CSS 原生 @page { margin: 20mm; } 徹底解決第二頁之後印表機邊界消失的問題。
  • 修正跨頁斷行：移除了段落的 page-break-inside: avoid; 限制，讓長段落文字可以自然跨頁斷行，不再將整塊文字硬推到下一頁。
  • 修正第一頁頂部空白：強制歸零文章首個元素（通常為 <h1>）的頂部 margin，解決列印第一頁頂端留白過大的排版異常。

2026-04-23 19:45
UI/UX Upgrade

v1.5 - 連續螢光筆與版面同步

2026-04-23 19:20
Feature Enhancement
  • 雙色連續螢光筆：新增藍色螢光筆，並將邏輯改為「模式切換」。啟動後，只要用滑鼠反白文字放開後就會自動上色，提升多段標記效率。

v1.4 - PDF 匯出與細節優化

2026-04-23 18:55
New Feature
  • 匯出 PDF：導入 html2pdf.js 模組，將原本儲存為 HTML 的功能升級為直接下載 PDF。
  • 來源網址頁尾：在列印與匯出文件時，於最底部自動附加來源網址，方便未來查閱出處（無網址則標示「手動貼上」）。

v1.3 - 大綱目錄與編輯輔助工具

2026-04-23 18:30
New Feature
  • 智慧目錄 (TOC)：左側新增動態大綱目錄，會自動掃描內文的 H1~H3 標籤生成清單，點擊可平滑滾動至該段落。

v1.2 - 完美貼上淨化與復原功能

2026-04-23 18:00
Core Logic Update
  • 剪貼簿淨化機制：攔截 Ctrl+V 事件。剝除貼上內容的外部樣式（黑底白字、自訂字型、固定寬高）與潛在腳本，僅保留純文字結構與圖片。
  • 絕對版面約束：加上嚴格的 CSS 寬高限制與自動斷字（word-wrap），確保貼上大型表格或超長英文不會撐破版面。
  • 復原與重置：導入原生 undo 指令（支援 Ctrl+Z 復原文字與圖片），並增加一鍵還原至網頁初始讀取狀態的「還原」按鈕。

Core Logic Update
  • 多重 Proxy 備援：新增多組代理伺服器輪替嘗試（如 codetabs, allorigins），提高對抗一般網站防抓取機制的成功率。

v1.0 - 核心功能上線

2026-04-23 17:00
Initial Release
  • 網址智慧提取：整合 Mozilla Readability.js 核心，自動剝除側邊欄、廣告與雜訊，僅保留乾淨文章本文。
  • 文件編輯模式：結合 HTML contenteditable 屬性，實踐如同 Word 般的點擊編輯與段落刪除體驗。
  • 圖片控制列：實作懸浮圖片控制列，支援點擊圖片進行等比例放大、縮小與刪除。
  • 無用空白過濾：撰寫演算法自動清理連續的空白 <br> 與無內容標籤，節省排版與列印空間。
